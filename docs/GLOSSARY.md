# Глосарій

Терміни FPV / БПЛА / ML, які трапляються в коді й документах.

## FPV / польот
- **FPV** (First Person View) — політ «від першої особи» через камеру на дроні.
- **Acro / Rate mode** — режим, де стік задає **кутову швидкість** обертання;
  дрон не самовирівнюється. Основний режим фрістайлу/рейсів (і Liftoff).
- **Angle / Self-level** — стік задає **кут нахилу**; відпустив — дрон вирівнявся.
- **Alt-hold** — автоутримання висоти. **Pos-hold / GPS-hold** — утримання позиції.
- **Rates** — коефіцієнти перетворення стіка в кутову швидкість (град/с).
- **Expo** — нелінійність стіка: плавно біля центру, різко на краях.
- **Deadzone** — мертва зона біля центру стіка (ігнор дрейфу).
- **Arm / Disarm** — увімкнення/вимкнення моторів.
- **Throttle** — газ (тяга моторів). **Yaw/Pitch/Roll** — рискання/тангаж/крен.
- **Mode 2** — розкладка пультів: газ+рискання ліворуч, тангаж+крен праворуч.
- **Fixed-wing** — літак (нерухоме крило), на відміну від мультиротора.

## Симуляція / фізика
- **Panda3D** — відкритий 3D-ігровий рушій (рендер, сцена, камери, ввід). Ставиться через `pip`.
- **Bullet** — фізичний движок (динаміка твердих тіл, колізії); у нас — вбудований у Panda3D (`panda3d.bullet`).
- **PBR** (Physically Based Rendering) — фізично коректне освітлення для реалістичної картинки (`simplepbr`).
- **dt / fixed step** — фіксований крок інтегрування фізики.
- **headless / offscreen** — рендер без вікна ОС, але з робочим графічним контекстом
  (для збору даних і навчання ML); у Panda3D — `window-type offscreen` (не плутати з
  `window-type none`, який взагалі не створює контексту рендеру — камера нічого не захопить).
- **PID** — регулятор (пропорційний-інтегральний-диференційний) для стабілізації.
- **Domain randomization** — рандомізація умов (світло, текстури) для стійкості ML.

## ML
- **YOLO** — сімейство моделей детекції об'єктів у реальному часі.
- **bbox** — обмежувальна рамка об'єкта (x, y, w, h).
- **mAP** — mean Average Precision, метрика якості детекції. **mAP@0.5** —
  при порозі перетину (IoU) 0.5; **mAP@0.5:0.95** — усереднено по кількох
  порогах IoU (суворіша, "справжня" метрика).
- **RL** (Reinforcement Learning) — навчання з підкріпленням.
- **Gymnasium** — стандартний інтерфейс RL-середовищ (`reset`, `step`).
- **PPO / SAC** — алгоритми RL (Stable-Baselines3).
- **Reward** — винагорода; **success rate** — частка успішних епізодів.
- **Policy** — політика: функція obs → action (тут → `ControlCommand`).
- **Observation / Action space** — простори спостережень/дій агента.
- **"Телепорт-obs"** — стратегія навчання (фаза 6): агент спостерігає ІДЕАЛЬНУ
  відносну позу цілі напряму з симуляції (як "телепортовану" з фізики), а не
  зашумлені детекції YOLO — простіше й швидше вчиться, перший крок кривої навчання.
- **Domain randomization** (у контексті ML-даних) — рандомізація ракурсів/дистанцій
  камери навколо цілі при записі датасету (`ml/data/scripted_flight.py`), не
  плутати з рандомізацією освітлення/текстур (те саме поняття, ширший сенс).
- **PIP** (Picture-in-Picture) — маленьке вікно-мініатюра поверх основного
  екрана; тут — показує кадр, який бачить `Detector`, з рамками детекцій
  (`render/detection_overlay.py`).
